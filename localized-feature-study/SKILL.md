# Localized feature study

Zero in on one struggling facial or body part with a practice sheet from photo refs (comic tutorial habit: arms, legs, eyes, brows, ears, hands).

## When

User (or a recognition fail) names a part: eyebrows, eyes, nose, mouth, ear, hand, or similar. Typical after [likeness-face-sketch](../likeness-face-sketch/SKILL.md) when one landmark is wrong and the rest of the head is usable.

## MUST / MUST NOT

- MUST isolate **one** named part per sheet (or a tightly related pair, e.g. brow + eye).
- MUST gather several close refs of that feature on the **same** person (or subject).
- MUST start with simple forms, then clean contours; optional light screentone.
- MUST write the rule learned (e.g. "brows thin, low, nearly straight").
- MUST re-apply onto the existing head / figure construction.
- MUST NOT redraw the entire character from scratch for every small fail.
- MUST NOT "fix" a landmark by changing hairstyle, age, or the whole page layout.

## Steps

1. Name the failing part in one phrase. Confirm with the user if ambiguous.
2. Gather 3-8 close refs of that feature on the same person (or subject). Crop tight; keep lighting variety if you have it.
3. Fill a sheet with small studies: front / 3/4 / profile if relevant. Same scale row, or one large plus satellites.
4. Start with simple forms (planes, wedges, lids as forms -- not eyelashes first).
5. Clean contours. Optional light screentone from shadow toward light, respecting form ([comic-construction-basics](../comic-construction-basics/SKILL.md)).
6. Note the rule you learned in a short caption on the sheet.
7. Re-apply onto the main head or figure. Change only that region plus whatever it forces (e.g. brow change may move the eye socket slightly).
8. Return to [likeness-face-sketch](../likeness-face-sketch/SKILL.md) or [kids-photo-coloring-page](../kids-photo-coloring-page/SKILL.md) with the updated construction.

## Common landmark checks

- **Brows:** thickness, arch vs straight, distance to the eye, inner-corner start.
- **Eyes:** opening shape, lid thickness, iris size vs photo, tilt, inner corner.
- **Nose:** bridge width, ball, nostril wing, how much it projects in 3/4.
- **Mouth:** closed vs open (honour user), lip thickness, corner position vs pupils.
- **Ear:** height vs brow-to-nose, bowl vs rim, how much shows at this turn.
- **Hand:** simple volumes (box palm, cylinder fingers); foreshorten; count digits.

## Do not

Redraw the entire character from scratch for every small fail -- isolate the part.
