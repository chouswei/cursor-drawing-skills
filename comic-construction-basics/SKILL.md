# Comic construction basics

Core craft that separates stiff amateur drawings from usable comic / illustration construction -- for likeness gifts, kids plates, and sequential art.

## When

- Drawings look stiff, flat, or inconsistent across angles.
- User asks for construction, gesture, ink craft, or how to stage a face on a page.
- Observational work needs a shared vocabulary (forms, focal point, hair stages).

This skill **pairs with** the other three observational skills; it does not replace the likeness gate.

## MUST / MUST NOT

- MUST pick a storytelling focal point before decorating.
- MUST block simple 3D forms (sphere / box / cylinder) before contours and detail.
- MUST keep the same character readable from more than one angle.
- MUST ink a clean pass over a rough underdrawing (do not invent the drawing in ink only).
- MUST stage hair as hairline -> mass -> flow -> detail.
- MUST keep screentone / hatch sparse on kids coloring finals unless asked.
- MUST NOT start with eyelashes, cloth noise, or hair strands on an unbuilt head.
- MUST NOT skip [likeness-face-sketch](../likeness-face-sketch/SKILL.md) when the job is a real person's face.

## Three pillars

1. **Storytelling intent** -- clear focal point; composition serves the read (rule of thirds, leading lines, negative space). On a single coloring plate, the face / subject is the focal point.
2. **Anatomy / structure in action** -- gesture and simple 3D forms before contours; weight and proportion; foreshortening when angled.
3. **Consistency** -- same character readable from many angles; lighting and scale coherent if environments appear.

## Step habits

- Forms / stick / cylinders when stuck; gesture when confident.
- Localized studies for weak parts ([localized-feature-study](../localized-feature-study/SKILL.md)).
- Clean ink pass over rough underdrawing.
- Hair: hairline -> mass -> flow -> detail (same order as likeness).
- Cross-hatch / screentone from shadow toward light, respecting form -- sparse on kids coloring finals unless asked.
